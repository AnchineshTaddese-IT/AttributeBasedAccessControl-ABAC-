<h1>Attribute-Based Access Control (ABAC) - Rules in Okta </h1> Created group rules in Okta using user attributes to automatically assign users to the appropriate groups. By leveraging department-based attributes, access can be managed consistently and aligned with each user's role within the organization.  <br /> 


<h2>Environments and Technologies Used</h2> 

- Okta

<h2>Operating Systems Used </h2> 

- Windows 11

<h2>The groups are titled IT, HR, Accounting for our IT, HR, Accounting departments. All of the rules automatically assign users to said groups upon Activation.</h2>
